# algorithm_visualizer

## 🧠 Algorithm Visualizer
Algorithm Visualizer is a beginner-friendly, interactive web application designed to help students and developers understand and visualize how common algorithms work. The project uses clean animations and intuitive UI to provide a more engaging way to learn algorithmic concepts, starting with sorting algorithms.

## 🚀 Features
**🔄 Sorting Visualizer**
- Animates different sorting algorithms (Bubble Sort, Selection Sort, etc.).
- Shows element swaps, comparisons, and completion states.
- Ideal for students and instructors during algorithm lessons.

**🌙 Day/Night Mode**
- Toggle between dark and light UI themes using a single click.
- Mode is applied site-wide for consistency.

**📱 Responsive UI**
- Mobile-friendly layout.
- Interactive sidebar menu toggle using animated icons.

**🧭 Navigation**
Sidebar links for easy navigation to: <br>
- Home
- Sorting Visualizer
- About Us

**🎨 Ionicons Integration**
- Clean icons for theme switching and menu toggles powered by Ionicons.
